# UZ COSMOS

A space and astronomy school for 10-to-18-year-olds in Uzbekistan: lessons in
physics and astronomy, quizzes and a daily challenge, a 3D Solar System, an
interactive lab, a live sky and a market of models bought with the fuel pupils
earn. In Uzbek, Russian and English.

**Live:** https://space-edu.duckdns.org
